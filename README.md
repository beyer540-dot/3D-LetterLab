# 3D LetterLab
Android-Studio-Projekt (Kotlin + Jetpack Compose).

Enthält Buchstabenauswahl A–Z, Zeichenfläche, Raster, Vorlagen-Schalter, Fingerzeichnung, Undo/Reset und drei Übungsschritte. Dies ist ein erster Prototyp, noch keine APK und noch kein drehbares 3D-Modell.

## APK erstellen
ZIP entpacken, Projektordner in Android Studio öffnen, Gradle synchronisieren und Build > Build Bundle(s) / APK(s) > Build APK(s) wählen.
